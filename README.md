# Student Management System with Pytest

A modular Python CLI application to manage student profiles, featuring automated unit testing implemented with **Pytest**. 

## Features
* **Modular Codebase:** Clean separation between data structure, logic management, and interface layers.
* **Student Directory:** Capabilities to register, catalog, and locate student records via custom IDs.
* **Automated Unit Testing:** Includes test coverage for backend calculations, banking class abstractions, and structural fixtures via `pytest`.

## How to Run Tests
1. Install pytest:
   ```bash
   pip install pytest
   ```
2. Run tests automatically in your terminal:
   ```bash
   pytest
   ```
